# Offshore Wind Development Structure 

---

# 1. Executive overview 

It provides a high-level overview of developer-side project management for bottom-fixed offshore wind farms.
The objective is to give insights into how and when complex, multi-layered stakeholders are involved throughout the entire project lifecycle. In addition, it highlights the link between the project process and WTG / FOU design.



---


# 1. Project Life Cycle Overview 

## 1.1 Stage gate structure and major activities 

| Phase                           | Gate                         | Major Activities                                                                                                                                                |
| ------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Concept & Origination**       | G0 – Concept Approval        | Market screening, site identification, high-level wind resource review, preliminary CAPEX estimate, initial stakeholder mapping                                 |
| **Site Securing**               | G1 – Site Secured            | Bid submission / auction participation, concession or lease agreement execution, early stakeholder engagement                                                   |
| **Development**                 | —                            | Environmental baseline surveys, metocean deployment, grid connection application, preliminary layout, early financial model                                     |
| **Revenue Structuring**         | G2 – Revenue Secured         | PPA / CfD negotiation and signing, tariff confirmation, revenue model finalization                                                                              |
| **Engineering (FEED)**          | —                            | Geophysical & geotechnical surveys, WTG selection, preliminary load envelope, foundation concept design, electrical concept design, installation strategy study |
| **Pre-FID Readiness**           | G3 – Technical Readiness     | FEED completion, grid alignment confirmed, contract negotiation substantially complete, updated CAPEX & schedule                                                |
| **Financing**                   | G4 – Financial Close         | Lender due diligence, insurance placement, debt agreements executed, financial model finalized                                                                  |
| **Investment Decision**         | G5 – FID                     | Board approval of full CAPEX, equity commitment, risk acceptance, transition from development to execution                                                      |
| **Execution Authorization**     | G6 – NTP (Notice to Proceed) | Contractors formally instructed to begin fabrication/manufacturing, payment milestones activated                                                                |
| **Fabrication & Manufacturing** | —                            | WTG manufacturing, foundation fabrication, OSS construction, cable production                                                                                   |
| **Transport & Installation**    | —                            | Port marshalling, vessel mobilization, foundation installation, OSS installation, cable lay, turbine erection                                                   |
| **Energization**                | G7 – First Power             | Export cable energized, OSS live, first turbine connected to grid                                                                                               |
| **Commissioning**               | —                            | Mechanical completion, electrical completion, grid code testing, performance verification                                                                       |
| **Commercial Operation**        | G8 – COD                     | Reliability run completed, commercial operation declared                                                                                                        |
| **Operations Setup & Handover** | —                            | O&M mobilization, spare parts readiness, control room activation, final documentation & handover                                                                |

----

## 1.2 Key Governance Logic


- G2 (Revenue Secured) reduces revenue risk
- G4 (Financial Close) reduces financing risk.
- G5 (FID) commits capital.
- G6 (NTP) activates execution contracts.
- G8 (COD) marks full revenue commencement.
